# Taller Introductorio a Análisis de bioimágenes

Este curso, impartido por la Unidad de Microscopía de la Universidad Mayor (UM2), está abierto a investigadores, estudiantes y miembros de la comunidad universitaria interesados ​​en una introducción al procesamiento de bioimágenes con FIJI. 

Este curso está diseñado para personas con pocos o ningún conocimiento de FIJI. Se ofrecen talleres más avanzados para usuarios con mayor experiencia.
